# Demo Flipkart Landing Page

A simple static landing page inspired by Flipkart, built using HTML and CSS.

## Project Overview

This repository contains a beginner-friendly frontend project with:
- A basic page structure (`header`, `main`, `footer`)
- Navigation links for common shopping categories
- Separate CSS files for layout/styles and utility classes

## Project Structure

```text
demo-flipkart-landing-page/
├── index.html
├── README.md
└── Css/
    ├── style.css
    └── utilties.css
```

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/arslanakhtar14062004/demo-flipkart-landing-page.git
   ```
2. Open the project folder.
3. Run `index.html` in your browser (double-click or use Live Server in VS Code).
